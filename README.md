# NGOConnect
## An Integrated Digital Information System for Education, Welfare, and Donation Management in Non-Governmental Organizations

NGOConnect is a **web-based, integrated information system** designed to digitally organize and streamline the core operational activities of Non-Governmental Organizations (NGOs). The system replaces fragmented and manual record-keeping practices with a **centralized, secure, and extensible platform** for managing beneficiaries, volunteers, and donations.

The project is developed as part of the **Software Engineering and Project Management (SEPM)** curriculum and demonstrates the practical application of **software engineering principles, system design methodologies, and full-stack web development** in addressing real-world social and administrative challenges faced by NGOs.

The system is architected with **scalability and extensibility in mind**, enabling future integration of analytics, reporting, and decision-support mechanisms to support transparent and data-informed NGO governance.

---

## 🚀 System Capabilities

### 🔐 Authentication Module (Prototype)

* Administrative login interface
* Password reset workflow
* Prototype-level authentication implemented for academic demonstration purposes
* Designed for future enhancement using database-backed authentication and secure password hashing

### 📊 Centralized Dashboard

* Aggregate view of key organizational metrics
* Total number of beneficiaries
* Total number of registered volunteers
* Cumulative donation value
* Card-based, clean dashboard UI for rapid situational awareness

### 👨‍🎓 Beneficiary Management

* Create and delete beneficiary records
* Maintain demographic and contextual attributes (age, education level, support category)
* Supports education-, health-, and welfare-oriented assistance programs
* Centralized beneficiary data management for improved transparency

### 🤝 Volunteer Management

* Add and remove volunteer profiles
* Maintain role assignments and contact information
* Enables structured volunteer coordination and tracking

### 💰 Donation Management

* Register and remove donation records
* Track donor identity, contribution amount, and donation purpose
* Real-time aggregation of donation statistics on the dashboard
* Improves accountability and financial visibility

### 🎨 User Interface Design

* Sidebar-based navigation architecture
* Application-style dashboard layout
* Consistent design language across all system modules
* Emphasis on usability, clarity, and accessibility

---

## 🛠️ Technology Stack

* **Frontend:** HTML5, CSS3, JavaScript
* **Backend:** Python (Flask Framework)
* **Database:** SQLite
* **Architecture:** MVC-inspired modular structure
* **Styling:** Custom CSS with dashboard-oriented UI design

---

## ⚙️ System Workflow

1. Administrator authenticates into the system
2. Dashboard presents real-time organizational statistics
3. Administrator manages:

   * Beneficiary records
   * Volunteer information
   * Donation transactions
4. All operational data is persisted in a centralized database
5. CRUD operations are reflected immediately within the system interface

---

## 🧠 Software Engineering Principles Applied

* Modular system architecture
* Separation of concerns (presentation, logic, and data layers)
* CRUD-based data modeling
* Template-driven UI rendering
* Maintainable and extensible codebase design
* Foundation for scalable system evolution
